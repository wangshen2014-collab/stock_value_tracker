Formula Notes

PE Z = (Current PE - historical PE mean) / historical PE standard deviation.

Value Range = historical PE min/max multiplied by current TTM EPS.

Normal Value = historical PE P10/P90 multiplied by current TTM EPS. It is usually more stable than min/max.

SEC point-in-time reconstructs historical PE as daily close divided by then-known TTM EPS using SEC filed dates. Current EPS fallback is less rigorous, but keeps the table useful when point-in-time EPS data is unavailable.

Green / yellow / red colors are only visual scanning aids, not buy or sell signals.
